# Contributing to PeopleOps Console

PeopleOps Console is a backend-focused Node.js/Express/SQLite employee-operations system.

Before a pull request, follow the README setup and run the repository's integration tests and production validation. Changes to migrations, auth, RBAC, lifecycle workflows, backups, or concurrency should include focused tests.

Preserve the $0-first architecture unless a concrete requirement justifies new hosted infrastructure.

A merged commit is not automatic approval for a production deployment.
