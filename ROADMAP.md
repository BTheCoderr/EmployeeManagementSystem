# PeopleOps Console Roadmap

This roadmap describes direction, not guaranteed dates.

## Shipped

- embedded SQLite persistence with ordered migrations
- Admin / Manager / Viewer RBAC
- onboarding and offboarding workflows
- employee timelines and global audit history
- optimistic concurrency for stale-write protection
- OpenAPI documentation, integration tests, Docker support

## Improving

- accessibility and UI polish
- negative-path integration coverage
- backup/restore operational documentation
- reporting and export ergonomics

## Exploring

- optional SSO adapters
- additional workforce analytics
- deployment recipes that preserve the portable $0-first architecture

## Product boundary

PeopleOps should remain a credible, portable business-system demo. New infrastructure should earn its complexity.
